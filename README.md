# Визуализация с NumPy и Matplotlib

> Учебные примеры графиков и анимации на Python: NumPy, Matplotlib и чтение числовых данных CSV.

**Стек:** Python · NumPy · Matplotlib

## Содержание

Блокнот с числовыми вычислениями и графиками, `Задание 6.py` с анимацией и `Задание 7.py` с чтением числового CSV.

## Запуск

```bash
python -m pip install numpy matplotlib
python "Задание 6.py"
```

Для `Задание 7.py` нужен файл `data.csv` в рабочей папке. Он отсутствует в текущем репозитории. Блокнот `Лаьораторная5.ipynb` можно просмотреть на GitHub или открыть в Jupyter.
